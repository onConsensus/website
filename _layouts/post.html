--- layout: default --- {%- assign section = site.data.sections | where: "slug", page.section | first -%} {%- comment -%} Embargo gating. A post under embargo renders the sealed-commit summary (`_includes/embargo-seal.html`) in place of its body, hero, and signature blocks. The byline, disclosures, edit history, and trust signals continue to render so readers can see what was promised and by whom. The build happens daily on cron, so a deadline that has passed lifts automatically on the next CI run. An embargo lifts when *every* declared gate has passed. Both `embargo_until` and `embargo_block` are optional; setting only one is the common case. {%- endcomment -%} {%- assign has_embargo = false -%} {%- if page.embargo_until or page.embargo_block -%}{%- assign has_embargo = true -%}{%- endif -%} {%- assign embargoed = false -%} {%- if has_embargo -%} {%- assign time_passed = true -%} {%- if page.embargo_until -%} {%- assign now_ts = site.time | date: '%s' | plus: 0 -%} {%- assign until_ts = page.embargo_until | date: '%s' | plus: 0 -%} {%- if now_ts < until_ts -%}{%- assign time_passed = false -%}{%- endif -%} {%- endif -%} {%- assign block_passed = true -%} {%- if page.embargo_block -%} {%- assign tip = site.data.bitcoin.tip_height | default: 0 | plus: 0 -%} {%- if tip < page.embargo_block -%}{%- assign block_passed = false -%}{%- endif -%} {%- endif -%} {%- unless time_passed and block_passed -%}{%- assign embargoed = true -%}{%- endunless -%} {%- endif -%} {%- assign embargo_seal = site.data.embargoes[page.slug] -%}
