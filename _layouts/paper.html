--- layout: default --- {%- comment -%} paper.html — annotated-paper page. A "paper" is a desk annotation of a work published *elsewhere*. The page is therefore two things stacked: a faithful bibliographic record of the original, and our editorial notes on it. The record is rendered as a definition list so it reads as reference material rather than prose; the notes are the Markdown body and get the normal article shell. Frontmatter on a `_papers/.md` file: title — the paper's own title, verbatim slug — must equal the filename without `.md` paper_authors — array of author names as published (NOT `_authors/` slugs) venue — journal / conference / publisher as published year — publication year (integer) paper_url — canonical link to the paper itself. Named `paper_url`, not `url`: Jekyll always populates `page.url` with the page's own permalink, so an external `url:` key would be shadowed. annotator — slug of an entry in `_authors/` (who wrote our notes) annotated — ISO date our notes were last revised abstract — the paper's abstract, quoted deck — our one-line editorial framing doi — optional DOI, bare (e.g. 10.1145/571637.571640) arxiv — optional arXiv id (e.g. 1807.04938) pdf_url — optional direct PDF link when it differs from `url` key_results — optional array of short strings; what the paper establishes tags — optional array math — optional bool; loads KaTeX when true `paper_authors` is deliberately distinct from the posts' `author` field: these are external researchers, not desk bylines, so they must never be resolved against `_authors/` or linked as if they wrote for us. {%- endcomment -%} {%- assign annotator = site.authors | where: "slug", page.annotator | first -%}
