{%- comment -%} edit-history.html — "View edit history" affordance for a post. Reads `site.data.changelog[post.slug]` (generated by `scripts/build_changelog.rb` from `git log`). The first commit that introduced the post file is intentionally excluded — only post-publish edits appear. A post with no recorded edits still renders the affordance, with an explicit "No post-publish edits yet" empty state so the trust signal is visible on every article. Parameters post — the post object (defaults to current `page`). {%- endcomment -%} {%- assign post = include.post | default: page -%} {%- assign edits = site.data.changelog[post.slug] -%} {%- assign edit_count = 0 -%} {%- if edits -%}{%- assign edit_count = edits.size -%}{%- endif -%}

  1. {{ e.date | date: "%-d %b %Y" }} {{ e.subject | escape }} {%- if e.url -%} {{ e.short }} {%- else -%} {{ e.short }} {%- endif -%}
    2. {%- endfor -%}

Each entry is a commit recorded after the article was first published. The original publication commit is intentionally omitted. Diffs link to the canonical git history; nothing is rewritten in place.
