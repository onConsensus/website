{%- comment -%} edit-history.html — "View edit history" affordance for a post. Reads `site.data.changelog[post.slug]` (generated by `scripts/build_changelog.rb` from `git log`). The first commit that introduced the post file is intentionally excluded — only post-publish edits appear. A post with no edits renders nothing. View edit history ({{ edits.size }})
    {%- for e in edits -%}
  1. {{ e.date | date: "%-d %b %Y" }} {{ e.subject | escape }} {%- if e.url -%} {{ e.short }} {%- else -%} {{ e.short }} {%- endif -%}
    2. {%- endfor -%}

Each entry is a commit recorded after the article was first published. The original publication commit is intentionally omitted. Diffs link to the canonical git history; nothing is rewritten in place.
